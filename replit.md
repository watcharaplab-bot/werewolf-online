# Project setup

This is a Node.js Werewolf multiplayer web app using Express and Socket.IO.

## Run

- Start the app with `npm start`.
- The server listens on `0.0.0.0` using `PORT`, defaulting to port 5000.
- Open the app through Replit Preview.

## Runtime notes

- Rooms and game state are stored in server memory.
- Restarting the workflow or publishing a new version clears all active rooms.
- No external services or additional secrets are currently required.
